# 線分ABの回転面 S の可視化

2点 A(1, 1, −1)、B(−3, 1, 3) を結ぶ線分 AB を z 軸のまわりに回転させてできる曲面 S（−1 ≤ z ≤ 3）を、3D で動かしながら見られる Web アプリです。

HTML ファイル 1 つでできていて、ブラウザで開くだけで動きます。

## 数学的な背景

### 線分 AB の媒介変数表示

線分 AB 上の点は、t ∈ [0, 1] として次のように表せます。

$$
P(t) = A + t(B - A) = (1 - 4t,\ 1,\ -1 + 4t)
$$

z = −1 + 4t なので、AB 上の点は x = −z、y = 1 を満たします。

### 回転面 S の方程式

高さ z の点から z 軸までの距離を r とすると、

$$
r^2 = x^2 + y^2 = (-z)^2 + 1^2 = z^2 + 1
$$

したがって S の方程式は

$$
S:\ x^2 + y^2 = z^2 + 1 \quad (-1 \le z \le 3)
$$

となり、一葉双曲面の一部であることが分かります。

| 高さ z | 断面の円の半径 r | 備考 |
|:---:|:---:|:---|
| −1 | √2 ≈ 1.414 | 下端（点 A の軌跡） |
| 0 | 1 | 最も細いところ（くびれ） |
| 3 | √10 ≈ 3.162 | 上端（点 B の軌跡） |

### なぜ円錐ではなく双曲面になるのか

AB は z 軸と交わらず、平行でもありません（ねじれの位置）。このような直線を回転させると一葉双曲面になります。アプリでワイヤーフレーム表示にすると、曲面が直線の集まり（線織面）でできていることを確かめられます。

### 参考：S と平面 z = −1, z = 3 で囲まれる立体の体積

$$
V = \int_{-1}^{3} \pi (z^2 + 1)\, dz = \pi \left[ \frac{z^3}{3} + z \right]_{-1}^{3} = \frac{40}{3}\pi
$$

## 使い方

### 起動方法

1. `index.html` をダウンロードまたは保存します。
2. ファイルをダブルクリックするか、ブラウザにドラッグ＆ドロップして開きます。

ライブラリを CDN から読み込むので、**インターネット接続が必要**です。

ブラウザによってローカルファイルがうまく開けない場合は、簡易サーバーを起動してアクセスしてください。

```bash
# Python 3 がある場合
python -m http.server 8000
# → ブラウザで http://localhost:8000/index.html を開く

# Node.js がある場合
npx serve .
```

### 画面の操作

| 操作 | 内容 |
|:---|:---|
| 左ドラッグ | 視点を回転 |
| マウスホイール | 拡大・縮小 |
| 右ドラッグ | 平行移動 |

### コントロールパネル

| 項目 | 説明 |
|:---|:---|
| 回転角 θ スライダー | 0°〜360° の範囲で、どこまで回転させた曲面を表示するかを指定します |
| ▶ 回転アニメーション | 線分 AB が z 軸のまわりを回り、曲面 S が描かれていくようすを再生・一時停止します |
| リセット | 回転角を 360° に戻し、視点を初期位置に戻します |
| ワイヤーフレーム表示 | 曲面の網目（直線の集まり）を表示します |
| 不透明にする | 曲面の半透明表示と不透明表示を切り替えます |
| 断面を表示 | 平面 z = 一定 による断面の円を表示します |
| 断面の高さ z スライダー | 断面の高さを −1〜3 の範囲で変更します |

断面を表示すると、その高さでの AB 上の点 P、断面の円の半径 r = √(z² + 1)、断面積 π(z² + 1) が数式で表示されます。

## カスタマイズ

ほかの線分で試したい場合は、`index.html` の次の部分を書き換えてください。

```js
const A = new THREE.Vector3(1, 1, -1);
const B = new THREE.Vector3(-3, 1, 3);
```

曲面の描画は A, B の座標から自動で計算されます。ただし、次の部分はこの問題の線分に合わせて直接書いてあるので、あわせて直す必要があります。

- パネルの方程式の表示（`data-tex="S:\ x^2+y^2=z^2+1 ..."`）
- `updateSection()` 内の AB 上の点 `P(-z, 1, z)` と半径 `r = √(z² + 1)` の式
- 断面の高さスライダーの範囲（`min="-1" max="3"`）
